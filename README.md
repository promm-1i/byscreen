# Byscreen PC program

The Windows program for Byscreen, the Android app that uses a tablet as a second monitor for a Windows PC.

- Download: `Byscreen-PC.zip` under [Releases](https://github.com/promm-1i/byscreen/releases/latest)
- Setup guide: https://noveriq.co.kr/byscreen/en/ (한국어: https://noveriq.co.kr/byscreen/)
- Tablet app: Google Play, "Byscreen"

Windows 10 (2004 or later) or Windows 11, 64-bit. Unzip and run `byscreen-host.exe`; it sits in the notification area.
If "Windows protected your PC" appears, choose More info → Run anyway.

Only the program files are published here, not the source code. The zip includes the Virtual Display Driver
for extended mode under its own MIT license (`drivers/vdd/LICENSE.txt`).
